RepairMe 

Aplicación móvil Android para la gestión integral de reparaciones de un servicio técnico especializado en teléfonos móviles, ordenadores y periféricos.

Desarrollada como Proyecto de Fin de Ciclo del Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM), 2025/2026.

¿Qué hace?

ClearRepair digitaliza y centraliza la gestión de un servicio técnico de reparaciones, eliminando el seguimiento manual y mejorando la comunicación entre empresa y cliente.

La aplicación distingue tres roles con funcionalidades diferenciadas:

Administrador

Crear y gestionar reparaciones
Registrar usuarios (clientes y técnicos)
Actualizar el estado de las reparaciones
Consultar el historial de reparaciones por cliente
Filtrar reparaciones por estado


Técnico

Consultar las reparaciones asignadas
Presupuestar reparaciones y enviar el presupuesto al cliente
Recibir notificaciones cuando el cliente acepta o rechaza un presupuesto


Cliente

Consultar el estado de sus reparaciones en tiempo real
Aceptar o rechazar presupuestos desde la app
Generar PDFs de presupuestos y facturas


Tecnologías utilizadas

Kotlin — lenguaje principal de desarrollo
Jetpack Compose — interfaz de usuario moderna y declarativa
Firebase Realtime Database — almacenamiento y sincronización de datos en tiempo real
Firebase Authentication — autenticación por email/contraseña e inicio de sesión con Google
Firebase Storage — almacenamiento de archivos
Android Studio — entorno de desarrollo
Git / GitHub — control de versiones y trabajo colaborativo
